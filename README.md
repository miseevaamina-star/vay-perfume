# VAY PERFUME — исходный код сайта

Статический сайт без сборки и без зависимостей. Открывается напрямую
файлом `index.html` или через любой статический хостинг (GitHub Pages,
Netlify, Vercel, обычный веб-сервер).

## Структура

```
index.html                    — публичный сайт
admin.html                    — админ-панель (защищена входом)
css/style.css                  — все стили публичного сайта
js/script.js                    — логика публичного сайта: каталог, фильтры,
                                  модалки, карусель отзывов, FAQ, меню,
                                  вступительная анимация. Каталог и отзывы
                                  подгружаются из Supabase, если он подключён
                                  (см. ниже), иначе — из локальных данных
                                  в этом же файле
js/admin.js                     — логика админки: вход, список товаров,
                                  добавление / редактирование / удаление,
                                  загрузка фото
js/supabase-client.js           — общий клиент Supabase (сайт + админка)
js/supabase-config.js           — сюда вписываются URL и anon-ключ проекта
                                  Supabase (см. supabase/README.md)
supabase/schema.sql              — SQL-схема базы данных (таблицы + защита)
supabase/seed_import.sql         — перенос текущего каталога и отзывов в базу
supabase/README.md               — пошаговая инструкция по настройке Supabase
assets/                          — логотип, favicon, фотографии 23 ароматов
                                  (him-01…him-15, her-01…her-08) и 7 скриншотов
                                  реальных отзывов (review-1…review-7)
```

## Как запустить локально

Файлы должны отдаваться веб-сервером (не просто открываться как
`file://`), иначе `fetch`/относительные пути картинок могут вести себя
не везде одинаково. Проще всего:

```bash
cd путь/к/проекту
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

или через Node: `npx serve .`

## Публикация на GitHub Pages

1. Создать репозиторий, положить в него содержимое этой папки
   (включая `index.html` в корне).
2. Settings → Pages → Source: ветка `main`, папка `/root`.
3. Сайт будет доступен по адресу вида
   `https://<username>.github.io/<repo>/`.

## Админ-панель и база данных (Supabase)

Каталог и отзывы можно редактировать двумя способами:

1. **Через `admin.html`, с сохранением в Supabase** — так, чтобы
   изменения сразу были видны всем посетителям сайта, с любого
   устройства, без правки кода. Это основной способ. Требует
   один раз настроить Supabase — подробная пошаговая инструкция в
   [`supabase/README.md`](supabase/README.md). Пока Supabase не
   настроен (файл `js/supabase-config.js` пустой), страница
   `admin.html` открыто говорит об этом и не пускает дальше — вход
   недоступен, ничего не ломается.

2. **Напрямую в коде** — ароматы и отзывы «по умолчанию» лежат в
   `js/script.js`, в массивах `SEED_FRAGRANCES` и `SEED_REVIEWS`.
   Это резервные данные: сайт показывает их, пока не подключена
   и не заполнена база в Supabase, а также как fallback, если
   Supabase временно недоступен.

Как только Supabase настроен и в базу перенесён каталог (см.
`supabase/seed_import.sql`), публичный сайт сам переключается на
загрузку из базы — никакой правки `index.html` или `script.js` для
этого не требуется.

Старый черновой механизм редактирования прямо на публичной странице
(кнопки «✎ Редактировать» с сохранением в localStorage браузера)
остался в коде отключённым (`IS_ADMIN = false` в начале `script.js`)
— он был лишь временной демонстрацией на этапе дизайна и теперь не
нужен, но ничего не удалялось.
